# Tutorial

Follow chapters **1 through 8 in order**. Each chapter introduces one idea and uses the same **`hello`** job example.

**Format:** goal → prerequisites → steps (where hands-on) → what you learned → next chapter.

After chapter 8, use [Guides](../guide/index.md) for specific tasks and [Reference](../reference/index.md) for schemas and CLI flags.

## Chapters

| # | Chapter | You will |
|---|---------|----------|
| 1 | [Introduction](01-introduction.md) | See what runs where and why kive exists |
| 2 | [First deploy](02-first-deploy.md) | Build the CLI, then deploy `hello` on one worker |
| 3 | [The model](03-the-model.md) | Name bucket, worker, job, allocation |
| 4 | [Project files](04-project-files.md) | Know what to edit vs what kive generates |
| 5 | [Build](05-build.md) | Run `kive build` and inspect the catalog |
| 6 | [Deploy and changes](06-deploy-and-changes.md) | Change the job and roll out an update |
| 7 | [Placement](07-placement.md) | Add a second worker and control where jobs run |
| 8 | [Go further](08-go-further.md) | Pick Guides and Reference pages for your next task |
